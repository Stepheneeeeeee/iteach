# 算法智学——数据结构与算法可视化互动学习系统

2026 年辽宁省大学生"iTeach"数字化教育应用创新大赛 · 工具系统类参赛作品

## 作品简介

面向高校《数据结构与算法》课程的互动教学工具系统，围绕"抽象算法难理解、课堂演示不直观、学情反馈不及时"三大痛点，提供**算法可视化实验室、知识点库、随堂测验、学情分析、学习仪表盘**五大模块：

- **算法实验室**：冒泡、选择、插入、归并、快速五种排序算法的逐步动画演示，伪代码同步高亮，比较/交换次数实时统计，支持自定义序列、单步控制与三档速度；
- **知识点库**：13 个核心知识点卡片，覆盖九大章节，含要点、公式与考点提示；
- **随堂测验**：26 道单选题，自动批改、即时解析，成绩与错题自动记录；
- **学情分析**：九章节掌握度雷达图、正确率柱状图、成绩走势与错题回顾；
- **学习仪表盘**：学习进度与成绩趋势总览，自动生成个性化学习建议。

## 运行方式

**方式一（推荐，零依赖）**：双击打开 `index.html`，在浏览器中直接使用。

**方式二（本地服务）**：

```bash
cd 算法可视化互动学习系统
python -m http.server 8000
# 浏览器访问 http://localhost:8000
```

环境要求：Windows / macOS / Linux 均可，推荐 Chrome、Edge 等现代浏览器。无需安装任何运行时或第三方依赖。学习记录自动保存在浏览器本地（localStorage），刷新或重启后仍保留。
